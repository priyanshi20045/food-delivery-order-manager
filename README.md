## Live Deployment

https://food-delivery-frontend-z8w8.onrender.com

Backend:
https://food-delivery-backend-75u4.onrender.com

## GitHub Repository

https://github.com/priyanshi20045/food-delivery-order-manager

## Features

- Add food delivery orders
- View all orders
- Filter orders by paid/unpaid status and maximum delivery distance
- Assign nearest unpaid order for delivery

## Tech Stack

### Frontend
- React
- Axios
- Vite

### Backend
- Java
- Spring Boot
- REST APIs

### Deployment
- Render

## Project Structure
frontend - React application
backend - Spring Boot application


## API Endpoints

GET /api/orders

POST /api/orders

GET /api/orders/filter

POST /api/orders/assign

## Run Locally

### Frontend
cd frontend
npm install
npm run dev


### Backend
cd backend
./mvnw spring-boot:run
